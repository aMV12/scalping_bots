# Scalping Bots

Репозиторий с набором версий скальпинг-ботов для криптовалютного рынка. Здесь собраны разные итерации алгоритма, отдельные ноутбуки под spot и futures, а также журналы сделок и таблицы с ошибками.

## Что делает проект

- получает рыночные данные через API Binance;
- тестирует и развивает несколько версий скальпинг-логики;
- хранит результаты сделок по отдельным версиям бота;
- сохраняет ошибки и диагностические данные для последующего анализа.

## Состав репозитория

- `scalping_bot_version*.ipynb` - разные версии стратегии и эксперименты с логикой бота;
- `scalping_bot_version_for_Binance_spot.ipynb` - вариант под spot-торговлю;
- `scalping_bot_version_for_Binance_futures.ipynb` - вариант под futures-торговлю;
- `таблицы со сделками бота/` - CSV-файлы с историей сделок по версиям;
- `таблица с возникающими ошибками/` - CSV-журналы ошибок и проблемных прогонов;
- `таблицы с историями свечей/` - вспомогательные рыночные данные.

## Технологии

- Python
- pandas, numpy
- matplotlib
- requests, asyncio
- python-binance

## Особенности

- Репозиторий отражает эволюцию стратегии по версиям, а не одну финальную реализацию.
- В ноутбуках есть код для работы с API-ключами Binance, но сами ключи в репозитории не хранятся.
- Проект больше подходит для анализа идей и истории экспериментов, чем для запуска "из коробки".
